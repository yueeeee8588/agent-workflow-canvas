# Agent Workflow Canvas (多 Agent 工作流画布 · 官方标准 App 版)

> **极客专享**：为 HanaAgent 打造的标准应用（manifestVersion: 2），提供确定性的复杂任务执行前评估、DAG 拓扑看板与用户审核发令门禁。

---

## 🌟 核心功能与亮点

1. **执行前评估与防偷跑门禁**：
   - 面对多步骤工程、跨模块改动、架构重构或需要委派子代理的复杂任务，模型严禁擅自提前修改业务代码；
   - 必须先完成执行前评估，拆解出正交独立的工作包，并在会话中展示 DAG 流程图卡片供用户审核。
2. **节点直接换人与动态指派**：
   - 每个任务节点内嵌精致的下拉选择框，支持从全景专员名录中调换执行人；
   - 底部提供「➕ 输入自定义助手 ID」入口，采用纯 DOM 水墨模态弹窗，输入后按回车即自动追加至全局，100% 免疫系统沙箱对 prompt 的拦截。
3. **四重全景触控与滑动导航**：
   - 左右悬浮翻页控制按钮（‹ / ›）；
   - 鼠标空白处抓手按住直接平移（Drag-to-Scroll）；
   - 普通鼠标滚轮横向直连映射；
   - 显式宣纸底色细滑块滚动条，告别截断遮挡。
4. **唯一法定开工发令信号**：
   - 用户确认人员排布后，点击卡片右下角的「🚀 立即执行」按钮；
   - 通过原生 `window.card.emit('execute_workflow', payload)` 投递发令事件，主控与子代理方可领命施工。

## 🚀 极速安装指南

### 第一步：解压放入应用目录
将本应用文件夹解压后完整放置到你的 Hana 数据目录下的 `apps/` 文件夹中：
```text
~/.hanako/apps/agent-workflow-canvas/
```
（例如 Windows 路径为 `C:\Users\<你的用户名>\.hanako\apps\agent-workflow-canvas`）

### 第二步：在应用市场中启用
1. 打开 Hana 桌面客户端，进入「扩展 / 应用市场」；
2. 刷新后在已安装或本地应用列表中即可看到 **「Agent 工作流画布」**；
3. 点击启用即可。应用会自动挂载 Webview 路由并向你的所有 AI 模型暴露 `render_workflow` 工具。

### 第三步：在助手全局规则中挂载契约（推荐）
在助手的系统提示词（System Prompt 或 AGENTS.md）中添加以下指令，让助手在规划复杂任务时无条件遵守发令门禁：

```markdown
# 复杂任务执行前评估与审核发令契约
遇到多步骤工程、跨模块改动、架构封装或涉及子代理协作的复杂任务：
1. 施工前严禁偷跑业务代码，必须先完成执行前评估，说明边界、分工与验收；
2. 调用 render_workflow 工具挂出支持节点换人的纯图形 DAG 流程图供用户审核；
3. 默认唯一开工信号是用户亲自点击卡片上的「🚀 立即执行」按钮，收到发令回执前主控和子代理均不得开工派发。
```
